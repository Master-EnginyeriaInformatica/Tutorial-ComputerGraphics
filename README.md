# Computer Graphics and Multimedia - 1st Activity

This repository contains the Unity project for the first Computer Graphics and Multimedia activity.

The project explores basic 2D gameplay concepts, including:

- Keyboard-controlled movement and rotation.
- Physics-based movement with `Rigidbody2D`.
- Moving an object towards a position selected with the mouse.
- Trigger responses, timed object removal, and object spawning.
- A simple randomly generated maze that can be rebuilt during play.

The activity was completed by following [CGM_WP1.pdf](CGM_WP1.pdf), which is included in this repository for reference.

Open the project with Unity and run the scene in `Assets/Scenes` to try the exercises.
